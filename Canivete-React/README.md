#  Canivete

My personal hub of daily use web apps, a Swiss Army knife for the small tools I use every day.

- **[Live version](https://daviarendreis.github.io/Canivete/)** *(the original vanilla JS version — the React rebuild isn't deployed yet)*

## Why I built it

I had a few small apps I'd built for my own use, scattered across different places. The problem: the effort to open and use them was high enough that I ended up never using them. So I brought them all together into one hub, lowering the barrier to zero, and Canivete became a tool I actually use every day, pinned right on my desktop.

## What's inside

- **Hub** - the home where all the apps live, each reachable from a single place.
- **Todo** - a task list where each task has a name, description, time and priority level. Tasks can be edited or deleted.
- **Tracker** - a habit counter with streaks. Each habit has its own name (editable), color and streak count.
- **Finance** - tracks your total balance, income and expenses. Add transactions through a form (description, amount, type, category) and see them all listed.

## Tech

Originally built in **vanilla JavaScript**, Canivete is currently being **rebuilt in React + TypeScript**, using **Radix UI** for the interface.
